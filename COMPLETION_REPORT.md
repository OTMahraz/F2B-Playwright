## 🚀 Prochaines étapes (3 minutes)

### 1. Installation
```bash
npm install && npx playwright install
```

### 2. Configuration
```bash
cp .env.example .env
```

### 3. Run tests
```bash
npm run test:smoke
```

### 4. Voir les rapports
```bash
npm run test:reporter
```
